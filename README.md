# Matemática com SciPy

Repositório desenvolvido para o trabalho acadêmico sobre a biblioteca **SciPy**, realizado na disciplina de **Matemática a plicada à computação**.

O objetivo deste projeto é apresentar a biblioteca SciPy, suas principais funcionalidades, aplicações matemáticas e sua relação com outras bibliotecas do ecossistema científico do Python.

---

## Objetivos do trabalho

Este trabalho tem como objetivos:

- Apresentar a biblioteca SciPy;
- Conhecer seus principais módulos;
- Demonstrar funções matemáticas disponíveis;
- Apresentar exemplos práticos utilizando Python;
- Mostrar aplicações do SciPy em diferentes áreas;
- Comparar o SciPy com outras bibliotecas matemáticas;
- Identificar suas principais vantagens e limitações.

---

# Como executar os exemplos

Siga o passo a passo abaixo para baixar o projeto, instalar as dependências e executar os exemplos.

## 1. Pré-requisitos

Antes de começar, é necessário ter instalado no computador:

- Python 3
- Git

Clone o repositório e com o arquivo aberto, clique no botão: Run Python File
